# Personal Portfolio

This project is a modern personal portfolio website built for a front-end developer who wants to showcase their skills, projects, and professional story in a clean and engaging way.

The site presents a responsive one-page experience with sections for a hero introduction, about section, skills overview, featured projects, and contact details. It is designed to feel professional, lightweight, and easy to navigate across desktop and mobile devices.

## Features

- Responsive portfolio layout
- Hero section with profile summary and contact links
- About section highlighting background and interests
- Skills section with technology badges
- Project cards with filtering and detailed dialogs
- Contact section for reaching out professionally
- Theme toggle and mobile-friendly navigation

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Lucide React

## Project structure

The app is organized into reusable components and data-driven sections so the content is easy to update:

- `src/data` contains profile, navigation, project, and skill content
- `src/components` holds the layout, sections, and shared UI elements
- `src/app` includes the page-level app structure and providers

## Getting started

```bash
npm install
npm run dev
```

To build the project for production:

```bash
npm run build
```
